## About the Project
InternSpace is a frontend-based internship search website designed to help students find internship opportunities across different technical domains in India. Students can search, filter, and explore internships based on their interests, preferred duration, and stipend.

## Features

### 1. Home Page
- Attractive welcome section.
- Website navigation.
- Explore Internships option.
- Internship search functionality.

### 2. Internship Listings
- Displays internships using responsive cards.
- Company name and internship title.
- Internship domain.
- Internship duration.
- Work mode.
- Required skills.
- Monthly stipend in Indian Rupees (INR).
- Apply Now option.

### 3. Search and Filter
Students can search internships by:
- Internship title.
- Company name.
- Domain.
- Required skills.

Domain filters include:
1. UI/UX Design
2. Data Structures and Algorithms (DSA)
3. Frontend Development
4. Backend Development
5. Python Development
6. Generative AI
7. Data Science
8. Cybersecurity
9. Cloud Computing
10. Java Development

### 4. Internship Details
- **Duration:** 1 month, 3 months, and 6 months.
- **Monthly Stipend:** ₹1,000 – ₹6,000.
- Search and clear filter options.
- Empty results and error handling.
- Responsive internship cards.

## Technologies Used
- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Search, filtering, and dynamic internship listings.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## Project Objective
The main objective of InternSpace is to simplify the internship search process for students by bringing internship opportunities from different technical domains into one platform.

It helps students discover opportunities, explore different technologies, and find internships that match their career interests.
